# ARMCAR Autoserwis demo

Independent Polish and Russian website proposal for ARMCAR in Warsaw. The owner has not approved it; it is labelled as a demo and excluded from search indexing.

Static HTML, CSS and JavaScript. No build step. All fonts are self-hosted with the IBM Plex license. Illustrations are original SVG drawings; no photos or people.

## Local preview

Run `python3 -m http.server 8080` in this directory. Open `/` for Polish or `/ru/` for Russian.

## Contact flow

Visitors can call, get directions or open the verified Instagram profile. The message helper composes and copies a description locally; visitors send it themselves through Instagram. There is no booking backend or automatic message delivery. The Google map loads only on request.
